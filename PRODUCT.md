# Headless

## What it is

Headless is Mojave Studio's free, public release standard for people building websites with AI agents. It turns the gap between a working first draft and a credible public website into a small, legible set of practices and an installable agent skill.

## Who it is for

Independent builders, designers, and small teams who move quickly with Claude, ChatGPT, Codex, or similar agents, but still want to ship sites that are accessible, searchable, secure, and intentional.

## Product promise

Make the site real before you call it done.

## Brand direction

Headless should feel like a publishing imprint with a point of view: kinetic, exacting, optimistic, and a little confrontational. It is not a developer dashboard, an AI-terminal pastiche, or a generic SaaS landing page. The visual language uses oversized geometric type, a sharp monochrome base, and one vivid, structural spectrum element that represents moving a draft through release.

## Experience principles

- Make the main action obvious: read the guide or give an agent the skill.
- Treat the release visual as meaningful context, not background decoration.
- Let typography carry hierarchy; avoid card grids and ornamental interface chrome.
- Keep animation optional, subtle, and fully disabled for reduced-motion preferences.
- Preserve semantic structure, visible focus states, strong contrast, and descriptive text alternatives.
